Provable · аудит доказательности для любых микроданных

Загрузите таблицу — получите отчёт о том, какие выводы она позволяет сделать

Строка таблицы — единица наблюдения: семья, человек, предприятие, школа. Группы — любые категории: регион, тип поселения, отрасль, год. Для каждой пары показателей Provable проверяет, есть ли связь между единицами внутри групп, только между группами или нет вовсе. Данные обрабатываются на этом компьютере.

1. Данные→2. Роли столбцов→3. Отчёт

1. Данные

CSV с заголовком; разделитель — запятая или точка с запятой. Большие таблицы сокращаются до 200 000 случайных строк.

2. Роли столбцов

Provable предложил роли автоматически — проверьте. Показатель — числовой столбец для проверки связей (до 15). Группа — категория, внутри которой сравниваются единицы. Одна из групп — группа сравнения: между её значениями проверяется агрегированная связь. Повторение — столбец (например, год), в каждом значении которого связь между группами должна повториться.

Отчёт

Что данные позволяют утверждать

Связи, подтверждённые тестами, — с формулировкой и доказательством.

Ловушки: выглядит как связь, но для единиц не подтверждается

Пары, где корреляция по всем единицам заметна, но внутри групп связи нет. Такие выводы об отдельных единицах публиковать нельзя.
