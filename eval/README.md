# Оценка качества ИИ-части Provable

Проверяется само приложение `out/provable.html`: скрипт открывает его в Google Chrome без окна и вызывает функции разбора вопроса и проверки утверждения.

## Наборы

| Файл | Состав | Роль |
|---|---|---|
| `benchmark_dev.json`, `benchmark_test.json` | 80 вопросов, 40 утверждений | разработка версий 2 и 3 (оба набора уже использованы для исправлений) |
| `benchmark_test2.json` | 40 вопросов, 30 утверждений | **контроль**: зафиксирован коммитом `c35c82d` до разработки версии 3, прогнан один раз |

Контрольный набор сложнее прежних: разговорные формулировки и слова вне словаря, направление связи без чисел, отрицания («не связаны»), доли словами («каждая третья»).

## Результаты на контрольном наборе

| Показатель | Версия 2 | Версия 3 |
|---|---|---|
| Вопросы: распознаны оба показателя или верный отказ | 27/40 | 27/40 |
| Посторонние вопросы отклонены | 4/4 | 4/4 |
| Утверждения: вердикт совпал с правильным | 20/30 | **29/30** |
| Ложные утверждения пойманы | 8/15 | **15/15** |
| Ложное утверждение принято за верное | 7 | **0** |

## Что добавлено в версии 3

- Направление связи по словам («больше», «реже», «снижает»; «чем больше…, тем меньше…»; «сельские» — нижний конец шкалы «город/село»).
- Отрицания: «не связаны» верно, только если связи на этом уровне действительно нет.
- «Внутри регионов» — вывод о семьях, а не о регионах.
- Доли словами: «каждая третья», «почти половина», «четверть».

## Локальная языковая модель: проверили и не взяли

| Модель | Результат на dev-пуле | Решение |
|---|---|---|
| Qwen2.5 3B (Ollama) | одна модель — 48/80 вопросов против 77/80 у словаря; придумывала показатели для посторонних вопросов | хуже словаря |
| Qwen2.5 7B (Ollama) | верно понимала разговорные слова, но отвечала 16–37 с на ноутбуке с 8 ГБ памяти и пересказывала цитаты своими словами | слишком медленно для работы, не вошла |

Главная оставшаяся слабость — слова вне словаря: такие вопросы система не распознаёт и отказывается, а не угадывает.
