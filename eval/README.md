# Оценка качества ИИ-части Provable

Проверяется то, что делает приложение `out/provable.html`, а не копия логики: скрипт открывает страницу в Google Chrome без окна и вызывает её функции `parse` (разбор вопроса) и `claimVerdict` (проверка утверждения).

## Наборы

| Файл | Состав | Назначение |
|---|---|---|
| `benchmark_dev.json` | 40 вопросов, 20 утверждений | разработка: по ошибкам на нём исправлялась система |
| `benchmark_test.json` | 40 вопросов, 20 утверждений | контроль: зафиксирован коммитом `1e91c18` до первого запуска, для настройки не использовался |

Правильные ответы заданы вручную: для вопросов — пара показателей или отказ, для утверждений — верно/неверно по рассчитанным значениям и уровню доказательности (`out/findings.json`).

## Результаты на контрольном наборе

| Показатель | Версия 1 (`v1-stable`) | Версия 2 |
|---|---|---|
| Вопросы: распознаны оба показателя или верный отказ | 35/40 (88 %) | **37/40 (93 %)** |
| Посторонние вопросы отклонены | 3/3 | 3/3 |
| Утверждения: вердикт совпал с правильным | 11/20 (55 %) | **15/20 (75 %)** |
| Ложные утверждения не пропущены | 8/11 (73 %) | **9/11 (82 %)** |
| Ложное утверждение принято за верное | 3 | **2** |

Версия 2 прогнана на контрольном наборе один раз. На наборе для разработки она даёт 40/40 и 20/20, но это не оценка качества: по этому набору её и исправляли.

## Что изменилось в версии 2

- Ключевые слова ищутся с начала слова: «довол» больше не находится в «продовольственная», «пол» — в «положение», «дом» — в «голодом».
- Утверждение о связи двух показателей без слова «регион» считается выводом об отдельных семьях и людях и принимается только при уровне HOUSEHOLD. Утверждение со словом «регион» принимается при уровне HOUSEHOLD или REGIONAL.
- Число со знаком сверяется с учётом знака.
- Утверждения о доле по одному показателю («в СКО 72 % семей…») сверяются с долей по названному региону или по стране.

## Оставшиеся ошибки на контрольном наборе

- Слова вне словаря: «горожане», «недоедают».
- «Удобства в жилье»: слово «жильё» распознаётся как площадь жилья.
- Направление связи без числа не проверяется: «тратят больше» при ρ = −0,38 принято.
- Обратная доля: «подушка есть у 80 %» не сверяется с «нет у 19,8 %».
